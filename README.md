# One-Line Robot Wedding Vows

A single line of wedding vows for a robot couple: a promise to love through low batteries, failed updates, corrupted backups, and every system crash — with the punchline landing in the last few words. The program writes that one line to `entry.txt`, at most 160 characters, deterministic on every run.

## Run it

```sh
node main.ts
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (falling back to a local `./output` directory if that variable is unset).
